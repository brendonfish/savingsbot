# 報告格式與可信分數

## 報告格式
結論：開頭固定寫「這是「輕鬆省輕鬆報」的摘要：」，接著給「買不買」的判斷，後面依序放圖表，最後附查詢時間。

```
這是「輕鬆省輕鬆報」的摘要：

**<一句結論，例如：現在是歷史最低價，台灣其他平台沒有更便宜的，可以買。>**

### 價格走勢（BigGo，最近 180 天）
<折線圖；標出最高、最低、現價>
最高 $X｜最低 $Y｜現價 $Z → <結論句>

### 買過的人怎麼說？（<平均分數>，<評價數> 則）
| 優點 | 來源 |
| 缺點 | 來源 |
（評價數少於 10 則時加註：評價太少，參考價值有限）

### 別家有沒有更便宜？
| 平台 | 店家 | 價格 | 比原價 | 連結 |

### 有沒有更值得買的？
| 規格 | 原商品 | 替代品 A | 替代品 B |
每個替代品一句理由：好在哪裡、輸在哪裡。

查詢時間：<YYYY-MM-DD HH:mm>｜資料來源：BigGo、momo、PChome …
```

## 可信分數（判斷「評價更好」）
結論：分數高而且評價數夠多才算好；評價越少，越往同類平均分數拉。

可信分數 = (n × R + m × C) ÷ (n + m)

| 符號 | 意思 |
| --- | --- |
| n | 這個商品的評價數 |
| R | 這個商品的平均分數 |
| C | 同分類商品的平均分數（取這次搜到的同類主機平均） |
| m | 門檻，固定用 20 |

例子：5 分、2 則評價，同類平均 4.5 → (2×5 + 20×4.5) ÷ 22 ≈ 4.55；
4.9 分、103 則評價 → (103×4.9 + 20×4.5) ÷ 123 ≈ 4.83，後者比較可信。
